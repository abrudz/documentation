# Default_FR

This parameter specifies the value of [`⎕FR`](../../language-reference-guide/system-functions/fr.md) in a clear workspace. It is `645` or `1287`, and its default value is `645`. Any other value is ignored.

The value can also be set on the [Session tab](../configuring-the-ide/configuration-dialog.md#session-tab) of the Configuration dialog box.
